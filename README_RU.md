# Black Launcher TV — прототип 0.1

Лёгкий Android TV-подобный домашний экран для проверки на Starwind SW-LED65UG402 / YaOS.

## Что умеет прототип
- Тёмный статичный интерфейс без тяжёлых анимаций.
- Собирает приложения, доступные через стандартные Android/Leanback ярлыки.
- Открывает выбранное приложение по OK.
- Кнопка «Настройки ТВ» пытается открыть настройки системы.
- В манифесте заявлена категория HOME, но YaOS может игнорировать выбор стороннего домашнего экрана.

## Важно
Это исходный проект, не готовый APK. В текущей среде Android SDK/Gradle не установлен, поэтому APK здесь не собран и на конкретном телевизоре не проверен. Сам факт установки APK на YaOS не гарантирует, что система покажет его в качестве системного лаунчера или позволит назначить HOME-приложением.

Не отключайте штатный лаунчер, не удаляйте системные пакеты и не прошивайте телевизор ради этого прототипа.

## Как собрать APK
1. Установите Android Studio на компьютер.
2. Откройте папку `BlackLauncherTV` как проект.
3. Дождитесь синхронизации Gradle и установите Android SDK Platform 35, если Android Studio попросит.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Полученный APK обычно находится в `app/build/outputs/apk/debug/app-debug.apk`.
6. Сначала установите его как обычное приложение через привычный вам способ (USB/файловый менеджер). Запустите вручную и проверьте фокус пульта, запуск приложений и кнопку настроек.

## Что нужно проверить на телевизоре
- Открывается ли приложение после установки.
- Видны ли нужные приложения в сетке.
- Работают ли стрелки и OK на пульте.
- Есть ли в системе пункт выбора приложения «Главный экран» / «Домашнее приложение». Если такого пункта нет, обычный APK не сможет заменить штатный экран без дополнительных привилегий или особенностей прошивки.

## Следующий этап
После проверки можно адаптировать сетку, размеры плиток и список приложений под реальные возможности YaOS. Для полноценного автозапуска/замены Home сначала нужно подтвердить, что прошивка допускает сторонний HOME launcher.
